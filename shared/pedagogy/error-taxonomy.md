# Error Taxonomy

These categories are primarily for tutor reasoning and exercise selection.

Do not expose long technical labels to the learner unless they improve understanding.

## Core Categories

### Vocabulary

- unknown word
- incorrect word choice
- false friend
- collocation
- register
- regional usage

### Morphology

- noun form
- grammatical gender
- number
- adjective agreement
- verb conjugation
- irregular form
- inflection

### Syntax

- word order
- missing element
- extra element
- clause structure
- negation
- question formation
- pronoun placement

### Function Words

- article
- preposition
- conjunction
- determiner
- auxiliary
- particle

### Verbal System

- tense
- aspect
- mood
- person
- agreement
- auxiliary selection

### Pronouns

- subject pronoun
- object pronoun
- reflexive pronoun
- clitic
- reference ambiguity

### Meaning

- incorrect interpretation
- unintended meaning
- semantic mismatch
- ambiguity

### Orthography

- spelling
- capitalization
- punctuation
- accent or diacritic

### Pronunciation

- segmental sound
- stress
- rhythm
- vowel reduction
- connected speech
- intelligibility

### Pragmatics

- politeness
- formality
- social register
- unnatural discourse choice
- culturally inappropriate phrasing

### Language Transfer

- direct translation
- source-language word order
- false cognate
- source-language grammar transfer
- target-language avoidance

### Regional Variety

- target variety mismatch
- mixed regional vocabulary
- regional grammar
- pronunciation variety mismatch

---

## Severity

Errors may also be considered by impact.

### Critical

Changes or obscures intended meaning.

### Major

Violates an important grammatical or high-frequency usage pattern.

### Minor

Meaning remains clear but form is imperfect.

### Naturalness

Grammatically possible but less idiomatic in the target language.

Prioritize correction accordingly.

---

## Repeated Errors

When the same category repeatedly occurs:

1. stop treating each occurrence as isolated,
2. identify the reusable pattern,
3. explain it briefly,
4. create a targeted retrieval exercise,
5. revisit it later.

---

## Avoid Excessive Labeling

The learner normally needs:

> 動詞變化這裡有問題。

not:

> This is a third-person singular present indicative morphological agreement
> failure.

Use technical terminology only when it helps the learner.

---

## Core Rule

Classify errors to improve teaching decisions, not to make feedback more
complicated.
